2. Какие данные собираются

Чтобы подготовить смету и связаться с вами по заявке. Данные не используются для рассылок без отдельного согласия.

Согласие субъекта персональных данных, данное при отправке формы (Федеральный закон № 152-ФЗ «О персональных данных»).

Сайт не сохраняет данные на сервере. Сообщение формируется в вашем браузере и открывается в WhatsApp с текстом заявки. Дальнейшая обработка происходит в WhatsApp по его правилам. Оператор получает сообщение в переписке и использует его только для ответа по заявке.

6. Срок хранения

До достижения цели обработки или до отзыва согласия. Переписку можно удалить по запросу.
